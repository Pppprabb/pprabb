## player3 分工明细（原型阶段）

### 负责模块（主导）
- **委托板（筛选/分页/进详情）**：`code/player3/pages/requests.html`
  - 目标：做“可玩的列表”——筛选、分页、点击进入详情。
  - 交互：筛选/分页/跳转详情（已在 `code/shared/site.js` 有基础逻辑），player3 负责把任务数据结构扩展得更丰富（字段更多、标签更合理）。
- **我的任务（占位页，后续增强）**：`code/player3/pages/my-missions.html`
  - 目标：展示“已接取/已完成/已放弃”的列表（原型阶段可先做静态或 localStorage）。

### 可交叉协作（配合）
- 与 player4 协作：任务条目点击后进入 detail 的字段映射（列表字段 ↔ 详情字段）。
- 与 player1 协作：公告（公共主页）与委托板的联动入口与文案。

### 交付物
- `requests.html`：委托卡片的图文信息（图片+描述）与筛选条件。
- `my-missions.html`：把“接取/完成/清空”做成可用交互（可用 localStorage）。
