## player4 分工明细（原型阶段）

- **详情展示页**：`code/player4/pages/detail.html`
  - 目标：让“详情页”成为全站信息承载中心：主视觉、信息表、正文、动作按钮（收藏/返回/联系）。

- **个人主页（头像入口）**：`code/player4/pages/profile.html`
  - 目标：个人信息 + 发布委托（上传图片 + 描述）+ 入口聚合。
- **人物介绍（页签单人展示）**：`code/player4/pages/characters.html`
  - 目标：页签一次只展示一个人物（更多图片素材 + 文字描述）。
