Banner 图片轮播

页面顶部的大图就是 banner，右下角有 1~4 数字指示器，点击可以切换图片，每隔 4 秒也会自动轮播。

如何换成你自己的图片：
1) 把图片放进 shared/p5ui/assets/examples/images/（或你页面同目录下）。
2) 打开 site.js，找到 bannerImages 数组（第 60 行左右），改成你的图片路径，有几张写几项：
var bannerImages = [ "../shared/p5ui/assets/examples/images/你的图1.png", "../shared/p5ui/assets/examples/images/你的图2.png" ]; 3) HTML 里的 banner 结构不用改，JS 会自动生成对应数量的指示器。

HTML 结构（头部 .site-hero 区域，不动就能用）：
<section class="site-hero"> <div class="site-banner"> <img id="bannerImg" class="site-banner__img" src="默认图片路径" alt="" /> <div class="site-banner__vignette" aria-hidden="true"></div> <div class="site-banner__indicators" id="bannerIndicators"></div> </div> </section>

表单校验（数据验证）

表单校验就是”提交前检查填写内容是否合规”，不合规就弹出红色提示框，不跳转页面。

本 demo 把校验逻辑写成了可复用函数（在 site.js 里，搜索 validateForm），校验规则支持：
· 必填（required: true）
· 邮箱格式（type: 'email'）
· 最小长度（minLen: 6）

你们复用时的步骤：
1) 把 site.js 里的 validateForm 函数复制到你自己的 JS 文件里。
2) 在你的 HTML 里加一个 <div id="formAlert" class="site-alert" hidden></div> 作为提示框容器。
3) 在表单 submit 事件里调用，自定义校验规则即可：
// 示例：校验”用户名必填 + 密码至少6位” var errs = validateForm(form, [ { name: 'username', label: '用户名', required: true }, { name: 'password', label: '密码', required: true, minLen: 6 } ]); if (errs.length) { showAlert(alertEl, errs[0]); // 显示第一条错误 return; } // 通过校验，继续执行...

用户状态（登录状态持久化）

登录成功后，把用户名存入 localStorage，侧栏的”当前用户”区域会自动显示。刷新页面也不会丢失（直到你退出登录）。

如何复用：
只需调用 site.js 里的 setStoredUser(name) 函数，传入用户名字符串即可：
// 登录成功后调用（例如在你的表单 submit 里） setStoredUser("joker"); // 写入 localStorage 并刷新侧栏显示 // 退出登录时调用 setStoredUser(""); // 传空字符串清除用户名 底层存储 key 是 p5_username，如果你不用 setStoredUser 也可以直接：
localStorage.setItem("p5_username", "joker"); // 写入 localStorage.removeItem("p5_username"); // 清除

图形绘制（Canvas）

Canvas 是 HTML 提供的”画布”标签，可以用 JS 在上面画文字、图形、图片。本 demo 演示：输入文字 → 选颜色 → 点击”绘制”，文字就会渲染在黑色画布上；点”清空”清除。

HTML 部分（复制这段到你的页面）：
<!-- 画布，width/height 决定实际尺寸 --> <canvas id="drawCanvas" class="site-canvas" width="560" height="260"></canvas> JS 部分（核心画文字逻辑，在 site.js 里）：
var canvas = document.getElementById("drawCanvas"); var ctx = canvas.getContext("2d"); // 背景 ctx.fillStyle = "#000"; ctx.fillRect(0, 0, canvas.width, canvas.height); // 文字 ctx.font = "bold 32px sans-serif"; ctx.fillStyle = "#ff0022"; // 换颜色就改这里 ctx.fillText("你的文字", 40, 80); 如果你只需要画图形（方块/圆/线），把 fillText 换成 fillRect/arc/moveTo+lineTo 即可，不需要改 HTML。
注意：正文章在页面上用 .show-plain，不使用小字号 .p5-text。

分页导航

分页就是把一大堆内容拆成多页显示，底部有"上一页 / 页码 / 下一页"按钮。本 demo 每页显示 3 条，点击页码会切换内容。

HTML 只需两个容器（id 名要和 JS 对应）：
<!-- 内容区 --> <div id="pageList" class="site-list"></div> <!-- 分页按钮区 --> <div id="pager" class="site-pager"></div> 在 site.js 里，改 pageData 数组换成你自己的内容（改这里）：
var pageData = [ { title: "条目1", desc: "描述文字" }, { title: "条目2", desc: "描述文字" }, // ... 想要几条就加几条 ]; var PAGE_SIZE = 3; // 每页显示几条，改这里 JS 的渲染函数（renderPage / renderPager）会自动根据数组长度算出总页数，不需要手动计算。

CROWD 帧动画（路人群众）

这是 P5R 特有的"路人群众"动画：12 张帧图片循环切换，角色向左移动并淡出，造成城市人流穿行的效果。

如何在你的页面里加入这个动画（纯 CSS，不需要 JS）：
1) 确保已引入 shared/p5ui/css/p5-ui.css（它内部已内嵌了所有帧图片和动画关键帧）。
2) 在你的 HTML 里加一个空 div：
<div class="site-crowd" aria-label="crowd frames"></div> 3) 在 site.css 里已有对应样式（搜索 .site-crowd）。如果你用的是独立 CSS 文件，复制以下样式即可：
.site-crowd { width: 100%; height: 130px; overflow: hidden; position: relative; background: transparent; /* p5-ui.css 里已定义 .p5-crowd 帧动画 class */ } 注意：容器尺寸固定（宽满 · 高 130px），超出范围的部分会被 overflow:hidden 裁掉，就像角色走进画面再走出去的感觉。

Switch（开关）

点击可以切换开/关状态，视觉效果已由 CSS 实现。需要 site.js 里的 JS 才能响应点击。
完整 HTML 结构（复制整段，包括里面所有 span 和 input，不能少）：
<!-- 初始关闭：p5-switch-off；初始打开：p5-switch-on --> <!-- 尺寸：p5-switch-size-small / medium / large --> <div class="p5-switch-ctn p5-switch-size-medium p5-switch-off" data-p5-switch> <input type="checkbox" aria-label="switch" /> <div class="p5-switch-bg-ctn"><span class="p5-switch-bg"></span></div> <span class="p5-switch-icon"></span> <span class="p5-switch-sub-icon"></span> </div> JS 如何工作（site.js 里已有，不需要自己写）：
site.js 会自动找到所有带 data-p5-switch 的元素并绑定点击事件， 点击时切换 p5-switch-on / p5-switch-off 这两个 class 来改变外观。
如果你想监听状态变化，在 JS 里这样写：
var sw = document.querySelector("[data-p5-switch]"); sw.addEventListener("click", function() { var isOn = sw.classList.contains("p5-switch-on"); console.log("开关状态：", isOn ? "开" : "关"); });

// site.js 里已有封装好的函数，直接调用： showNoti("通知内容文字"); // 角色头像在 site.js 里 showNoti 函数内，改 p5-portrait-img 的 src 换人物 ② Message（剑动画弹出消息） — 顶部弹出一条带剑动画的消息条，自动消失：

SVG 图标（人物/按钮图标）

SVG 图标分两种：按钮图标（back/next 等箭头类）和人物图标（P5R 角色肖像）。

第一步：在 <head> 里引入图标定义脚本（必须）：
<script src="../../p5-ui-main/src/assets/svgs/p5-icon-btn.js"></script> <script src="../../p5-ui-main/src/assets/svgs/p5-icon-party.js"></script> 第二步：在页面里写 <svg use> 引用（把 #back 或 #akechi 换成你要的图标名）：
<!-- 按钮图标 --> <div class="p5-svg-ctn"> <svg class="p5-svg-btn" aria-hidden="true"> <use href="#back" xlink:href="#back"></use> </svg> </div> <!-- 人物图标 --> <div class="p5-svg-ctn"> <svg class="p5-svg-party" aria-hidden="true"> <use href="#akechi" xlink:href="#akechi"></use> </svg> </div> 可用的图标名称（在 p5-icon-btn.js / p5-icon-party.js 文件里搜索 id= 查看）：
· 按钮类（p5-svg-btn）：#back、#next 等
· 人物类（p5-svg-party）：#akechi、#mona、#anne、#ryuji 等角色名

Text（正文文字样式）

small 小字号 medium 默认字号 large 大字号 extra-large 超大
.p5-text 是 P5R 风格的正文文字 class，有四种尺寸。纯 CSS，不需要 JS。
注意：.p5-text 会让文字很小并使用 P5R 字体，正文段落建议搭配 .show-plain 避免字体混乱。

用法（直接加 class，标签不限）：
<!-- 四种尺寸 --> <span class="p5-text text-size-small">小字号说明文字</span> <span class="p5-text">默认字号（medium）</span> <span class="p5-text text-size-large">大字号强调文字</span> <span class="p5-text text-size-extra-large">超大字号展示</span> <!-- 正文段落（不用 .p5-text，用 .show-plain 保持清晰可读）--> <p class="show-plain">这是正常可读的正文段落，推荐正文都加 show-plain。</p> 常见用途：在 Notification 里的小标题（text-size-small），Slider 里的数值标签（.p5-text）。
